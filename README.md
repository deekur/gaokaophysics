# 高考：普通*高*等学校招生全国统一*考*试


 ***（以下均特指物理科目）***

<details>
  <summary><b>1. 高考改革史</b></summary>

  - 1952：统一高考制度建立
  - 1952-1957：统一高考下分省与统一的争论
  - 1958：分省命题
  - 1959-1965：全国统一试卷
  - 1966-1976：高考停止
  - 1977：高考恢复，*因故*分省命题
  - 1978-1984：全国统一试卷
  - 1985：上海自主命题
  - 1986：广东启动标准化改革
  - 1986-1990：标准化改革继续推广
  - 1991：广东回归全国卷，三南试验启动
  - 1992：三南试验继续
  - 1993：三南试验结束，3+2方案开始实行
  - 1994：3+2方案继续推广
  - 1995：3+2方案推广完成
  - 1996：3+2方案与上海方案并存
  - 1997：天津，山西，江西启动***新课程***改革
  - 1998：新课程改革继续
  - 1999：广东启动3+X改革
  - 2000：广东调整3+X，山西、浙江、江苏、吉林加入3+X
  - 2001：河南加入3+X
  - 2002：广西加入3+X，3+X改革完成
  - 2003：全国继续实行3+X方案
  - 2004：北京，天津，江苏自主命题，***新课标***改革启动
  - 2005：新课程改革完成
  - 2006：四川，重庆自主命题
  - 2007：山东自主命题，教育部开始为海南单独命题，新课标改革继续
  - 2008：新课标改革继续
  - 2009：安徽，浙江，福建自主命题
  - 2011-2013：新课标改革继续
  - 2014：新课标改革继续，***新高考***改革启动
  - 2015：新课标改革完成
  - 2016：安徽，福建，山东，重庆，广东，停止自主命题
  - 2017：四川停止自主命题
  - 2018-2019：新高考改革继续
  - 2020：山东，海南自主命题
  - 2021：福建，河北，湖北，湖南，重庆，辽宁，广东自主命题
  - 2022-2023：新高考改革继续
  - 2024：安徽，甘肃，广西，贵州，江西，吉林，黑龙江自主命题
  - 2025：河南，云南，陕西，四川，山西，内蒙古，宁夏，青海自主命题
  - 2026：新高考改革继续

</details>

 ***名词解释（为统一标准，命名方式可能与主流称呼，《试题分析》不同）：***
- **全国卷**：存在两套课程标准时，年份较早的对应的*统一*高考试题，只存在一套时，指*统一*高考试题
- **新课程卷/大纲卷**：依照1996版课标（大纲）命制的统一高考试题  
  - 2000-2004 相对旧课程叫新课程卷  
  - 2005-2014 相对新课标叫大纲卷
- **旧课程卷**：存在新课程卷时，其余的统一高考试题，依照1986版课标命制
- **新课标卷**：依照2003版课标命制的统一高考试题
- **新高考卷**：依照2017版课标命制的统一高考试题

  <summary><b>5. 内容说明</b></summary>

  <br>

  **1. 试卷收录标准**
  - 理科综合中物理部分拆分后单独成卷
  - 本仓库不收录文理综合、理科基础、自选模块中试题
  - 普通本科院校可参与招生且非院校直接招生 
  - **普通高中**学生均可参加
  - 春季高考加一条：难度与**当年**普通高考相当
  
  据此，部分年份、省份的大专招生专用试卷，大学单独、联合招生试卷，近年山东，广东，天津，福建等省所谓~~春季高考~~试卷不收录

  **2. 已知缺失试题**

  **普通高考**
  - 1958，1977剩余地区
  - 1977预选试题（见5.4）

  **3. 关于副题**

  本仓库不收录**副题**，**无论是否启用过**，值得注意的是，2003未启用副题，2008四川，甘肃45区市的延考区卷不是副题，副题又叫**备用卷**、**付题**（“付”为“副”的二简字）

  **4. 关于预考题**

  本仓库不收录预考试题，但1977除外，因为只有1977预考和高考均由省级及以下单位命题；关于1977的黑龙江初试，江苏初考，浙江预选是否算作预考，这里采用[此观点](https://doi.org/10.13397/j.cnki.fef.2023.05.010)
 
   **5.关于浙江新高考选考试题**
   
   为了不重不漏，文件夹/2017下收录2017届考生高二或高三参加选考的试题，/2018及以后收录高三的试题
